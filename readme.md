# Прототипы — Сервис бронирования «Сладкие сны»

## Задание 2: прототипы пользовательских интерфейсов

### Страницы
| Файл | Описание |
|---|---|
| `index.html` | Главная: шапка (название + слоган), приветствие, кнопка «Перейти в каталог», подвал с контактами |
| `catalog.html` | Каталог: шапка, фильтр (категория, цена, места), 6 карточек номеров, кнопки «Применить» / «Сбросить фильтр», «Забронировать» |
| `booking.html` | Бронирование: поля Имя, Фамилия, Телефон, E-mail, Дата заезда, Дата выезда + валидация + сообщение об успехе |

### Как запустить
1. Склонировать репозиторий.
2. Открыть `index.html` в браузере (или запустить `python -m http.server` в папке `prototypes/`).
3. Перейти в «Каталог» → выбрать номер → «Забронировать» → заполнить форму.

### Что реализовано
- **Фильтрация** по категории, цене (от/до), количеству мест.
- **Сброс фильтра** — очищает поля и возвращает 6 случайных номеров.
- **Передача выбранного номера** на страницу бронирования через `?room_id=`.
- **Валидация** (на прототипе — JS; в итоговом сайте — серверная):
  - Имя/Фамилия: кириллица, пробелы, точки, тире.
  - Телефон: `+7(ХХХ)ХХХ-ХХ-ХХ`.
  - E-mail: стандартный формат.
  - Даты: `ДД.ММ.ГГГГ`, выезд позже заезда.
- **Сообщение об успешной отправке** заявки.
